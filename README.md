# ✨ Bella Studio — Site para Salão de Beleza

Projeto de desenvolvimento front-end criado para simular o site institucional de um salão de beleza. O Bella Studio apresenta os serviços do estabelecimento, sua identidade visual e formas de contato com os clientes.

🔗 **Acesse o site:** https://mariaisabelsf.github.io/bella-studio/

## 💻 Sobre o projeto

O objetivo foi desenvolver uma página moderna, elegante e responsiva, utilizando tecnologias fundamentais do desenvolvimento web.

O projeto também faz parte da minha jornada de aprendizado e prática em desenvolvimento front-end.

## 🚀 Funcionalidades

- Página inicial com apresentação do salão.
- Seção sobre o estabelecimento.
- Apresentação dos serviços oferecidos.
- Galeria de imagens.
- Seção de contato e agendamento pelo WhatsApp.
- Menu de navegação entre as seções.
- Layout responsivo para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
